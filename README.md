# UNV Камеры — Android

Быстрое приложение для просмотра камер и регистраторов Uniview (UNV) с записью и архивом.

## Установка
Откройте **Releases** справа на странице репозитория → последняя версия → скачайте `UNV-Kamery-*.apk` и установите.
APK собирается автоматически GitHub Actions после каждого изменения в `main`.

## Возможности
- **Поиск камер в сети** — ONVIF WS-Discovery + проверка порта RTSP 554 по всей подсети. «Добавить все» одним нажатием.
- **Ручное добавление** по IP, логину и паролю, кнопка «Проверить» показывает картинку прямо в окне.
- **Регистраторы (NVR)** — номер канала или сразу N каналов.
- **Сетка 1/2/3 в ряд** — в сетке лёгкий субпоток (s1), на весь экран — основной поток (s0), переключатель HD/SD.
- **Низкая задержка** — LibVLC, RTSP по TCP, аппаратное декодирование, автопереподключение.
- **Зум** щипком и двойным тапом.
- **Запись** без перекодирования (MPEG-TS): постоянная (в фоне, переживает перезагрузку) или разовая кнопкой ●.
  Файлы режутся по 5–60 минут, старые удаляются по лимиту места.
- **Архив**: по камерам и дням, перемотка, ±10 с, скорость до 16×, следующий/предыдущий файл, «Отправить».

## Адреса потоков UNV
- основной: `rtsp://IP:554/unicast/c1/s0/live`
- дополнительный: `rtsp://IP:554/unicast/c1/s1/live`
- `c1` — номер канала (для NVR).

Если модель использует другой адрес — укажите свой RTSP URL в настройках камеры.
