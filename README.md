# UNV Камеры — Android

Быстрое приложение для просмотра камер и регистраторов Uniview (UNV) с записью и архивом.

## Установка
Откройте **Releases** справа на странице репозитория → последняя версия → скачайте `UNV-Kamery-*.apk` и установите.
APK собирается автоматически GitHub Actions после каждого изменения в `main`.

## Возможности
- **Поиск камер в сети** — ONVIF WS-Discovery + проверка порта RTSP 554 по всей подсети. «Добавить все» одним нажатием.
- **Ручное добавление** по IP, логину и паролю, кнопка «Проверить» показывает картинку прямо в окне.
- **Регистраторы (NVR)** — номер канала или сразу N каналов.
- **Сетка 1/2/3 в ряд** — в сетке лёгкий субпоток (s1), на весь экран — основной поток (s0), переключатель HD/SD.
- **Низкая задержка** — LibVLC, RTSP по TCP, аппаратное декодирование, автопереподключение.
- **Зум** щипком и двойным тапом.
- **Запись** без перекодирования (MPEG-TS): постоянная (в фоне, переживает перезагрузку) или разовая кнопкой ●.
  Файлы режутся по 5–60 минут, старые удаляются по лимиту места.
- **Архив**: по камерам и дням, перемотка, ±10 с, скорость до 16×, следующий/предыдущий файл, «Отправить».

## Распознавание людей
Работает целиком на телефоне, в фоне, по каждой камере с включённым переключателем на вкладке «Лица».

- **Поиск лиц по всему кадру** — SCRFD-500M (InsightFace): полный кадр + перекрывающиеся плитки ~560 px,
  поэтому находятся и мелкие лица (18–30 px) у краёв и вдали.
- **Отпечаток лица** — ArcFace MobileFaceNet (InsightFace, WebFace600K), выравнивание по 5 точкам
  (глаза, нос, уголки рта), усреднение с зеркальной копией.
- **Трекинг** — лицо отслеживается между кадрами, отпечатки копятся с весом по качеству;
  решение «кто это» принимается по треку, а не по одному кадру.
- **Строгое решение** — порог сходства (с поправкой на чёткость лица) + отрыв от второго кандидата.
- **Самообучение** (можно выключить) — уверенно узнанные лица с камер пополняют образцы человека.

Замер на LFW (4 321 фото, 158 человек; половина — «знакомые» по 5 фото, остальные — «незнакомцы»),
доля правильно узнанных знакомых при 1% / 0,1% ложных узнаваний незнакомцев:

| Условия | Было (FaceNet) | Стало, 1 кадр | Стало, трек 3 кадра |
|---|---|---|---|
| Лица ~50 px | 75,4% / 54,0% | 99,8% / 99,6% | 100% / 100% |
| Лица 32 px + сжатие JPEG | 7,6% / 2,8% | 88,0% / 77,0% | 99,5% / 98,3% |
| Ночной ИК (ч/б) против цветных фото | — | 99,7% / 99,3% | 100% / 100% |

Модели InsightFace распространяются авторами для некоммерческого исследовательского использования.

## Адреса потоков UNV
- основной: `rtsp://IP:554/unicast/c1/s0/live`
- дополнительный: `rtsp://IP:554/unicast/c1/s1/live`
- `c1` — номер канала (для NVR).

Если модель использует другой адрес — укажите свой RTSP URL в настройках камеры.
